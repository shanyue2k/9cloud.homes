隐私政策

最近更新日期：2026年1月1日

九云深知个人隐私对您的重要性。我们始终恪守“用户隐私高于一切”的核心准则。本隐私政策旨在透明向您说明我们如何收集、使用及坚决不记录您的任何个人上网数据。

🛡️ 1. 严格的不保留使用日志承诺

✨ 九云郑重承诺：在您连接和使用九云网络加速服务的整个过程中，我们坚决不记录、不监视、不存储任何用户使用日志！

具体包含且不仅限于以下项目：

  • 不记录浏览历史： 我们不会追踪、检查或保存您访问的具体网址、域名或在线搜索关键词。
  • 不记录 DNS 查询： 所有的域名解析请求均通过专有的无痕加密 DNS 进行处理，不保留任何解析查询记录。
  • 不记录通信内容与载荷： 所有数据包在离开您的设备时即经过高强度对称加密，服务器仅充当盲态数据转发通道，无法且绝不解密您的通信内容。
  • 不记录用户源 IP 映射： 服务器不会将用户的真实物理 IP 地址与所分配的出网 IP 或特定访问目标建立持久关联日志。
  • 不记录连接时间戳： 我们不会长期留存用户精确的上线、下线时间或会话持续时长。

📊 2. 我们仅收集的最小必要信息

为了向您提供基础的账户管理、订单计费及客户服务，我们仅在您自愿提供的情况下收集以下极简信息：

  • 账户信息： 用于注册和登录的电子邮件地址（建议使用 ProtonMail 或任意匿名邮箱）、经不可逆加盐哈希加密的账户密码。
  • 订阅与用量总额： 您的当前套餐类型、生效到期日期以及周期内的累计总流量消耗数值（仅为总字节数统计，用于流量配额限制，绝不包含流量来源与去向）。
  • 技术支持工单： 您主动发起客户服务时所提供的沟通内容与报错截图。

🔐 3. 顶级数据安全防护机制

九云的底层服务器集群均基于无盘化（RAM-Only）运行架构设计，系统日志统一重定向至临时内存 /dev/null，服务器重启或断电后任何临时运行数据均彻底灰飞烟灭，杜绝任何实体磁盘取证或恶意窃取数据的可能性。

🔄 4. 政策修订与联系我们

我们可能会不定期微调本隐私政策以反映技术架构优化。如有任何关于隐私保护或数据安全方面的建议与疑问，请随时通过用户控制台工单系统与我们的隐私合规团队联系。
